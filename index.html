01 Personal Project

RabbitHole

An event-driven video platform where uploads trigger an AI-powered processing pipeline — transcoding, speech indexing, and semantic search across your entire library.

ECS FargateEventBridgeSQSffmpegClaude VisionAWS TranscribeTerraformReact
ECS Fargate over Lambda for transcoding — ffmpeg workloads are CPU-bound and long-running, and Lambda's 15-minute limit and cold starts would have killed the experience.
Three AI services had to fail independently. Claude Vision, Transcribe, and vector embeddings each run as an independent async step, so one failure never breaks the pipeline.

02 Co-Founded · Proprietary

QuicLens

A multi-tenant research analytics SaaS for neurodegenerative disease labs — replacing manual R scripts and Excel with structured, cloud-native plate analysis and audit-ready records.

AWS CDKLambda (Docker)API GatewayDynamoDBWorkOS SSOAnthropic APITypeScript
The math had to be right. Built a 92-test scientific validation suite verifying every calculation against the lab's own researcher-validated ground truth before a single user touched it.
Isolation, not just application logic. One misconfigured query could leak one lab's data to another — enforced at the DynamoDB partition key and the IAM boundary.

03 AWS Academy Capstone

PureZen

A fully serverless AI spa booking platform with a conversational concierge that takes guests from service discovery to confirmed appointment — grounded in live availability, so it physically cannot hallucinate an open slot.

AWS CDKLambdaDynamoDBAnthropic ClaudeOllamaReactFastAPI
Constraints drove the design. Started in an AWS Academy sandbox with no GPU and CPU-only Ollama inference — 10–40s generation times, which is exactly what drove the regex-first routing.
Never answers from memory. Services resolve against the real catalog, availability comes from DynamoDB, and booking actions are deterministic state machines.
